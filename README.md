# Reccito API

A receipt management platform that enables businesses to create, manage, and
share digital receipts with customers through QR codes, mobile apps, and web
interfaces.

## Key Features

### 🏢 **Multi-Tenant Architecture**
- Organization and store hierarchy
- Scoped API access and permissions
- Isolated data per organization

### 📱 **Digital Receipt Management**
- Create and store digital receipts
- Generate QR codes for easy customer access
- Barcode generation for physical receipts
- Time-limited QR codes for security

### 🔐 **Authentication & Security**
- API key authentication for merchants
- JWT token authentication for customers
- Phone-based customer verification with SMS
- Rate limiting per organization
- Permission-based access control

## Data Formats

### Dates and Times
Timestamps are ISO 8601. Most are UTC with an explicit offset
(`2024-01-15T14:30:00+00:00`); a few older fields may omit the offset —
treat any timestamp without one as UTC.

### Currency and Amounts
Monetary amounts are serialized as **decimal strings** (not numbers), with
a separate `currency` field. This avoids floating-point precision loss and
keeps every money field consistent across the API:
```json
{
    \"total_amount\": \"12.99\",
    \"currency\": \"GBP\"
}
```
Request bodies still lenient-accept a JSON number for amounts, but the
published contract and every response are string-only.

### ULIDs
Receipt IDs use ULID format for better performance and sortability:
```json
\"01HZXYZ123456789ABCD\"
```
